# askesis-ai — прокси к Groq

Клиент Askesis работает без бэкенда, поэтому ключ модели нельзя держать во фронтенде: всё, что попадает в `VITE_*`, вшивается в собранный бандл и видно любому посетителю сайта. Этот воркер держит ключ у себя и отдаёт наружу только готовую программу тренировок.

Что он делает:

- принимает запросы только с origin из `ALLOWED_ORIGINS`;
- проверяет Firebase ID-токен (подпись, `aud`, `iss`, срок) — значит дёрнуть его может только залогиненный пользователь вашего проекта;
- сам собирает промпт из структурированных ответов пользователя, поэтому его нельзя использовать как бесплатный чат с моделью;
- выкидывает из ответа модели упражнения с несуществующими id.

## Развёртывание

```bash
cd worker
npm install
npx wrangler login
npx wrangler secret put GROQ_API_KEY
npm run deploy
```

`wrangler secret put` спросит ключ в консоли — он уйдёт в Cloudflare и не попадёт ни в git, ни в бандл. Ключ берётся в [Groq Console](https://console.groq.com/keys).

После деплоя wrangler напечатает адрес вида `https://askesis-ai.<ваш-субдомен>.workers.dev`. Пропишите его в `client/.env`:

```
VITE_AI_WORKER_URL=https://askesis-ai.<ваш-субдомен>.workers.dev
```

Если фронтенд задеплоен не на `askesis-coach.web.app`, поправьте `ALLOWED_ORIGINS` в `wrangler.toml` и передеплойте.

Важно: `FIREBASE_PROJECT_ID` (`askesis-web`) — это id Firebase-проекта, по нему проверяется `aud` в токене. Он не совпадает с именем сайта хостинга (`askesis-coach`), и это нормально.

## Модель

Задаётся переменной `GROQ_MODEL` в `wrangler.toml`, по умолчанию `llama-3.3-70b-versatile`. Groq периодически снимает старые модели с обслуживания — если воркер начнёт отвечать ошибкой про `model_decommissioned`, посмотрите актуальный список на `https://console.groq.com/docs/models` и поменяйте значение.

Ответ запрашивается в режиме `response_format: json_object`: схему параметром Groq не принимает, поэтому форма JSON описана в системном промпте, а несуществующие id упражнений отсеиваются уже в воркере.

## Локальная разработка

```bash
npm run dev
```

Воркер поднимется на `http://localhost:8787`; для локального фронтенда пропишите этот адрес в `VITE_AI_WORKER_URL`. `localhost:5173` уже есть в списке разрешённых origin.
